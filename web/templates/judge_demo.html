这一页只有一个主张: 一条结论要在这套系统里被记成成立, 必须走完一条固定的证据阶梯, 而同一条阶梯会对证据不足的主张给出 refuted 或 inconclusive。 页面上每个数字都是从账本表里现读的, 任何一格都可以要求看它背后那一行。 This page makes one claim: for a finding to be recorded here as supported, it had to climb a fixed evidence ladder, and the same ladder returns refuted or inconclusive for claims the evidence does not carry. Every figure below is read live from the ledger, so you can ask for the row behind any of them.
